# 年度辦公日曆資料

系統只依「官方已公告」的辦公日曆計算工作天，**不自行猜測尚未公告的假日**。
尚未匯入完整年度日曆的年份，期限一律標示「暫估」，並在畫面顯示警示。

| 檔案 | 說明 |
| --- | --- |
| `2026.json` | 115 年（2026）政府行政機關辦公日曆表，依行政院人事行政總處 114.06.13 核定公告整理；執行 `npm run db:seed` 時匯入。 |
| `sample-official-format.csv` | 政府資料開放平臺官方 CSV 欄位格式範例。 |

## 匯入新年度

1. 至[政府資料開放平臺「中華民國政府行政機關辦公日曆表」](https://data.gov.tw/dataset/14718) 下載該年度 CSV。
2. 以管理員登入 →「系統設定」→「工作天設定」→「匯入官方辦公日曆」。
3. 先按「預覽差異」檢查期限異動，再填寫原因並確認匯入。
4. 匯入後至「期限重新計算」套用變更。

支援格式：
- 官方 CSV：`西元日期,星期,是否放假,備註`（是否放假 2=放假、0=上班；逐日全年資料，筆數等於全年天數時自動視為完整日曆）
- 簡易 CSV：`date,type,description`（type 可為 `HOLIDAY`／`放假` 或 `MAKEUP_WORKDAY`／`補行上班`；需勾選「此為官方完整年度日曆」）
- JSON：同 `2026.json` 格式，或官方欄位之物件陣列。
